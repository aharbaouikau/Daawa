# Daawa Platform

Modern multilingual Dawah platform based on cards, videos, texts and social sharing.

## Features

- Multilingual content
- AI translation
- Social media sharing
- Video, image and text cards
- Tags and categories
- Quran and Sunnah resources
- Mobile ready architecture
- TikTok style feed

## Technologies

### Frontend
- Next.js
- Tailwind CSS
- Framer Motion

### Backend
- FastAPI
- PostgreSQL
- SQLAlchemy

### Mobile
- React Native

### Deployment
- Render
